EJEMPLO 2: RELOJ DIGITAL

Este ejemplo práctico combina varios métodos del objeto Date para construir un reloj digital en tiempo real.

La función mostrarHora() recupera la hora, los minutos y los segundos actuales, los formatea y los inserta en un elemento HTML con el id="reloj".

Crucialmente, setTimeout(mostrarHora, 1000) se llama a sí mismo recursivamente cada 1000 milisegundos (1 segundo), lo que garantiza que la hora se actualice continuamente, simulando el funcionamiento de un reloj en vivo en la página web.

IMPORTANTE:

  • Posteriores ejemplos veremos como formatear la hora con dos dígitos
  • La función setTimeout(mostrarHora, 1000) es algo avanzado para los objetivos del módulo, aunque se incluye como ejemplo de interactividad que ofrece JavaScript
